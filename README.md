# pico-gameboy
For week 5 of half life I will be making a raspberry pi pico gameboy. I found a really cool repo that uses peanut GB to emulate GB games onto a pico, so I am going to use that. I'm also going to be creating a PCB to connect all of my components instead of just using a bunch of jumper wires. I think I'll cad a case myself, just to customize it.
